# Word Monster Slayer

A simple browser app for practicing spelling words while defeating a monster with physical dice rolls.

## Rules implemented

- Enter a list of words separated by commas.
- Monster HP is computed as: `number_of_words * 18`.
- Child writes each word 5 times by clicking **I wrote it once**.
- Parent/child rolls physical dice and manually types damage.
  - Normal mode: 1 die (typical 1–6)
  - Mastered mode: 3 dice (typical 3–18)
- Monster is defeated when HP reaches 0.

## Run

Open `index.html` in any browser.
